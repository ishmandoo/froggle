# Froggle 🐸

A daily word game for geniuses. New puzzle every day. (It's always frog.)

## How to Play

1. Open `index.html` in your browser
2. Guess the 4-letter word in 6 tries
3. Green = right letter, right spot. Yellow = right letter, wrong spot. Gray = not in the word
4. Don't worry, you'll get it

## Features

- Daily puzzle with streak tracking
- Shareable results
- Hard Mode (does absolutely nothing)
- Increasingly desperate hints
